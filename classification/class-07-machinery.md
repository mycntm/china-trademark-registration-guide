**Class heading (中文)**

机器和机床；马达和引擎（陆地车辆用的除外）；机器联结器和传动机件（陆地车辆用的除外）；非手动农业器具；孵化器；自动售货机。

**Class heading (English)**

Machines and machine tools; motors and engines (except for land vehicles); machine coupling and transmission components (except for land vehicles); agricultural implements other than hand-operated; incubators for eggs; automatic vending machines.

> A China application covers **10 items per class** (extra items are charged individually), and protection generally runs per sub-class rather than across the whole class — see [the class selection guide](../guides/05-nice-classification-guide-china.md).
