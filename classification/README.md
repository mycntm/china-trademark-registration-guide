## 为什么必须看「类似群」

中国把每个类别再划分为若干**类似群**（sub-classes）。同类别但不同类似群的两个商品，通常**不构成类似商品**，因此一标一类只选 10 个项目时，如果全部集中在一个类似群，其余类似群等于没有保护。本表把每个商品项按类似群归组，就是为了让你一眼看出「我的 10 项到底覆盖了哪几个类似群」。

In China, protection generally extends across a **sub-class**, not across the whole class. Two items in the same class but different sub-classes are not automatically similar — which is why a flat 10-item selection can leave gaps. Items below are grouped by sub-class for exactly that reason.

### CSV 字段 / Schema

`data/nice-classification-zh-en.csv`（UTF-8 with BOM，Excel 可直接打开）

| 字段 | 含义 | 示例 |
|---|---|---|
| `class_code` | 类号 01–45 | `09` |
| `class_zh` / `class_en` | 类别中英文名称 | `电子科学仪器` / `Scientific, electrical and optical apparatus` |
| `subclass_code` | 类似群代码 | `0901` |
| `subclass_zh` | 类似群中文名称 | `计算机及其外部设备` |
| `item_code` | 官方商品编码；**可为空**，且并不唯一 | `C090142` 或空 |
| `item_zh` / `item_en` | 商品/服务项目中英对照 | `可下载的手机应用软件` / `downloadable mobile phone applications` |
| `item_type` | 项目类型（见下） | `china_specific` |

`item_type` 取值：

| 值 | 含义 | 条目数 |
|---|---|---:|
| `standard` | 国际标准项目（WIPO 基础清单） | 10,748 |
| `china_specific` | 中国特有项目（如「可下载的手机应用软件」） | 2,015 |
| `acceptable_name` | 可接受的规范名称，通常无官方编码 | 19,902 |

> **注意**：`item_code` 不能作为唯一键——576 个编码在源数据中被用于不同商品，另有 19,902 条可接受名称没有编码。唯一标识请使用 `class_code + subclass_code + item_zh`。

### 用法示例 / Quick start

```python
import pandas as pd

df = pd.read_csv('data/nice-classification-zh-en.csv', encoding='utf-8-sig', dtype=str)

# 中→英：查某个中文商品属于哪一类
df[df.item_zh.str.contains('手机应用软件', na=False)][['class_code', 'subclass_zh', 'item_en']]

# 英→中：海外客户用英文查中文规范名称
df[df.item_en.str.contains('cosmetics', case=False, na=False)][['class_code', 'item_zh']].head(20)

# 某一类的所有类似群
df[df.class_code == '09'].groupby('subclass_code').size().sort_values(ascending=False)
```
