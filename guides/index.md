## Two facts that underlie all five

**The statutory clock is not the practical clock.** Substantive examination has a 9-month statutory ceiling, but straightforward files clear in 3–4 months. A clean application usually registers in **7–9 months**; only a file that runs to every limit reaches 12–15 months. Full split table: [statutory vs practical timelines](01-how-long-does-china-trademark-registration-take.md).

**Protection runs per sub-class, not per class.** China's 45 Nice classes split into 495 sub-classes (类似群). Ten items chosen from a single sub-class leave the rest of the class unprotected — the most common and most expensive mistake in Chinese filings. See the [classification index](../classification/index.md).
